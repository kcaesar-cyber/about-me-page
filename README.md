 # Milestone 3 - Accessibility & Visual Design
## Accessibility Fixes
- Fixed low contrast: Changed header background from light pink to dark plum #7A2E4B with white text to pass WCAG AA contrast.
- Fixed missing nav on index.html: Added same navigation to all three pages.
- Fixed broken link: Renamed project.html to projects.html so nav links work.
- Added descriptive alt text to all images.
- Added labels, fieldset/legend, and aria-describedby error messages to the contact form.
## Visual Design - Gestalt Principles
- I used proximity to group my project cards: cards that belong together are close together with 24px gap in a grid.
- I used similarity to make all cards look the same: same white background, border, padding, and font so users know they are the same type of content.
## Color Palette
- Background: #FDF6F8, Header: #7A2E4B, Text: #2E1A22, Cards: #FFFFFF. Same palette on all pages.
